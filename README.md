# SimplyTerm Plugin Registry

Official plugin registry for [SimplyTerm](https://github.com/arediss/SimplyTerm). The app fetches `plugins.json` to discover, install, and update plugins.

## How it works

```
repos.json (source of truth)     ──→  GitHub Action (daily cron)  ──→  plugins.json (auto-generated)
  List of plugin repositories            Fetches manifest.json             Full plugin index served
  (one PR to add your plugin)            + latest GitHub release            via GitHub Pages
```

- **`repos.json`** — The manually maintained list of plugin repositories. Plugin developers submit a PR to add their repo here (once).
- **`plugins.json`** — Auto-generated by a GitHub Action. Contains full metadata for every plugin (name, version, download URL, etc.). **Do not edit manually.**
- The GitHub Action runs **daily**, on **push to `repos.json`**, or via **manual trigger**.

## Publishing a plugin

### 1. Create your plugin repository

Your repo must contain a `manifest.json` at the root:

```json
{
  "id": "com.yourname.your-plugin",
  "name": "Your Plugin",
  "version": "1.0.0",
  "api_version": "1.0.0",
  "description": "What your plugin does",
  "author": "Your Name",
  "license": "MIT",
  "category": "tools",
  "keywords": ["keyword1", "keyword2"],
  "permissions": ["ui_notifications"],
  "main": "index.js"
}
```

### 2. Create a GitHub Release

- Create a `.zip` file containing `manifest.json` and `index.js` (and any other plugin files)
- Name the zip asset **`plugin.zip`** for a stable download URL
- Create a GitHub Release and attach the zip

### 3. Submit to the registry

Open a Pull Request adding your repository to `repos.json`:

```json
{
  "plugins": [
    { "repository": "existing/plugin-repo" },
    { "repository": "yourname/your-plugin-repo" }
  ]
}
```

That's it! The GitHub Action will automatically pick up your plugin metadata and generate the registry entry.

## Updating your plugin

Just create a new GitHub Release in your repository with an updated `plugin.zip`. The registry will detect the new version on its next run (daily, or trigger it manually).

No need to update this repository.

## Automatic cleanup

The Action automatically removes plugins from the registry when their repository is:

- **Deleted** (404)
- **Archived**

This keeps the registry clean without manual intervention.

## Available categories

| Category       | Description                        |
| -------------- | ---------------------------------- |
| `themes`       | Visual themes and color schemes    |
| `productivity` | Workflow and productivity tools    |
| `security`     | Security and credential management |
| `devops`       | DevOps and infrastructure tools    |
| `tools`        | General-purpose utilities          |
